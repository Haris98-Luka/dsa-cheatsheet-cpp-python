# Stack

**LIFO** – Last In, First Out. Think of a pile of plates.

| Operation | Time |
|-----------|------|
| push | O(1) |
| pop | O(1) |
| peek | O(1) |
| isEmpty | O(1) |

## Real uses
- Undo / redo
- Browser back button
- Function call stack (recursion)
- Expression evaluation and bracket matching

## Practice problems
- Valid parentheses (included here)
- Reverse a string using a stack
- Next greater element
- Evaluate postfix expression
